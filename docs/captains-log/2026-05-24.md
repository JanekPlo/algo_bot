- **ADR-007** authored in English (first ADR under the new language convention recorded on 2026-05-21). Title: `007-risk-adjusted-metrics.md`.
- **`algo_bot/metrics.py`** — hand-rolled pure functions over `pd.Series` with no external metrics library. Public surface: `infer_periods_per_year`, `log_returns`, `simple_returns`, `total_return`, `cagr`, `sharpe` (static), `rolling_sharpe`, `sortino`, `max_drawdown` (returns `(dd_pct, duration)`), `calmar` (trailing 36m default with pragmatic fallback on shorter series), `mar_ratio` (separate metric, not a Calmar alias), `recovery_time`, `profit_factor`, `win_rate`, plus `MetricsSummary` dataclass and `summarize()`. Log returns are used internally for annualised metrics (additive across time → exact √n scaling); simple returns are used for narrative metrics. Annualisation factor inferred from index spacing with `calendar="crypto"` default (365 days/year); fallback to 365 with a `logger.warning`. Edge cases (zero variance, zero DD, no losing trades, no trades, never-recovered) return `NaN` and emit `logger.warning`. Never-recovered drawdown is represented as `pd.Timedelta.max` internally and `inf` in the summary.
- **Cross-strategy correlation extension** added in the same session at Janek's request, anticipating post-MVP portfolio analytics: `strategy_correlation(equities, method="pearson"|"spearman", on="log_returns"|"equity") -> pd.DataFrame` (inner-join over the time intersection, accepts either `dict[str, pd.Series]` or `pd.DataFrame`) plus `mean_pairwise_correlation`. Lives in `algo_bot.metrics` for now; spin-off to a future `algo_bot.portfolio` module is deferred until portfolio analytics grow beyond two helpers.
- **`tests/test_metrics.py`** — deterministic fixtures with hand-computed reference values (Sharpe from `log_returns=[0.01, 0.03]`, DD on `equity=[100, 110, …, 90, …, 110]`, `profit_factor=3.0` from `trades=[10, -5, 20, -10, 15]`).
