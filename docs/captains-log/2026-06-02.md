## Phase 2 — opening

`docs/ROADMAP.md` Phase 2 section was rewritten in this brain-Claude session to match the Phase 1 level of detail. It now lays out 8 working sessions with prerequisites, sub-deliverables (code and docs), and value statements per session, plus a planned-ADR table (ADR-011 microstructure in Session 3, ADR-012 MVP go/no-go in Session 8, optionally ADR-013 diagnostics package in Session 5 or 6).

**Initial state of Phase 2:**

- `bot_data/processed/` empty — no historical OHLCV data on disk yet. Session 2 fixes.
- `config/bghtrend_b1..b4.yaml` are random-search sweep spaces with `__mode: random, __n: 5, __seed: 101` (or per-file equivalent), each spanning ~17 parameter dimensions. They are not four concrete parameter sets — they are four sweep configurations. Session 1 must clarify what differs between them and why (and whether the difference is principled or accidental).
- `algo_bot/strategies/bghtrend_pullback.py` carries an explicit economic thesis in its header docstring (trend defined by EMA21/89/200, pullback to EMA89 within an ATR band, xtrender momentum filter, ATR trailing stop, R:R 1:1.5). Session 1 turns this into a deep reference and a parameter taxonomy.
